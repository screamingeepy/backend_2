# PH Revival
A feature complete, rewritten version of the 2010s Flash game, Pixie Hollow. Compatible with both flash browsers and Ruffle.

Thank you to everyone who contributed in bringing this game back. To Jessi, for your sanity writing 90% of the game, Sunrise Games for being so amazing, Rocket for everything you've done, LittleCat for otpgo, and the lovely community for keeping this game alive. We couldn't have done this without you.
